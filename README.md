\# 🛍️ ShopLite - Brownfield Capstone Project



ShopLite is an enhanced e-commerce web application developed as part of the capstone project under `mm-learning-group-1`. This project builds upon an existing brownfield baseline by introducing advanced search, category filtering, user order history, and an administrative management dashboard.



\---



\## 🚀 Key Features Added (Enhancements)

1\. \*\*Product Search \& Category Filters:\*\* Real-time search bar and category dropdown filtering.

2\. \*\*Order History:\*\* Ability for users to view past orders and order statuses.

3\. \*\*Admin Dashboard:\*\* Secure CRUD management interface for administrators to add, update, and delete catalog products.



\---



\## 📁 Project Structure

\- `server.js`: Node.js \& Express backend API server.

\- `public/`: Frontend static assets (`index.html`, `login.html`, `script.js`).

\- `docs/`: Architecture and design documentation (`HLD.md`, `LLD.md`, `wireframes.md`).
